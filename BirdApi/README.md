# Models 
*----------------------------------------------------------------------------------------------------------------------------------------------------*

*AiModels.cs*

модели для отправки и получения информации от апи пайтона

*AuthRequest.cs*

для отправки в контролер авторизации

*MainTable.cs*

главная таблица с запросами пользователя, имеет поля айди пользователя(UserId), 
то что он ввел (InputQuery) и так же он ссылаеться на другие таблицы в зависимости от запроса, 
если пользователь хочет найти вид птицы по url картинки птицы то будет запись в таблице ImageBirdTable 
но и в главной таблице будет запись с двумя полями которые будут ссылаться на таблицу ImageBirdTable
с помощью параметров Type(тип таблицы по запросу, ImageBirdTable, soundBirdTable и Info) а так же айди
элемента в таблице IdTable, таким образом я храню ввод пользователя и его айди в одной талице для удобной 
статистики а информацию об ответе в других по типу запроса. много текста но не знаю как короче и понятнее обьяснить

*ImageBirdTable.cs/SoundBirdTable.cs*

хранит ответ от апи пайтона а именно Confidence(увереность) и (Image/Sound)Url(звук/картинка) вид птицы 
тут не храниться потому что он есть в MainTable(для статистики) а он ссылаеться на ImageBirdTable/SoundBirdTable 

*InfoBirdTanle.cs*

тоже самое что и ImageBirdTable/SoundBirdTable но хранит ответ от пайтона совсем другой, 
Appearance(внешность) Habitat(ареал обитания) Diet(рацион питания) и айди для нумерации и 
ссылки на MainTable

*User.cs*

модель пользователя с 
Username              - (его именем)
PasswordHash          - (захешированый пароль)
CreatedAt             - (дата создания аккаунта)
WalletAdres           - (необязаетльный параметр для криптокошелька чтобы купить пожписку)
HasSubscription       - (наличие подписки или нет через bool, по сути кеш, чтобы не проверять каждый раз через блокчейн)
SubscriptionExpiresAt - (конец подписки, по сути кеш, чтобы не проверять каждый раз через блокчейн)

Services

*BirdAiServices.cs*

он имеет функции PredictImageAsync/PredictAudioAsync/PredictBirdInfoAsync и порты для работы с 
пайтон ии, имено через этот сервис происходит работа с пайтон 

*CheckBirdPassServices.cs*

IsLimitExceededAsync - проверка наличия подписки\лимита по айди пользователя
CheckDailyLimitAsync - проверка лимита по запросам если у пользов нету подписки

*BlockchainService.cs*

HasSubscriptionAsync - функция проверки наличия подписки через блокчейн

*RabbitMqProducer.cs*

SendRabbitMqMessageAsync - асинхроная операя через rabbit mq которая создает канал связи и
отправляет запрос консумеру на добавление записи в таблицу BaseQuery

*RabbitMqConsumer.cs*

создает слушателя который подклчаеться к каналу от продюсера и делает запись в бд
